## 📌 Engineering Principles

- **Build for users:** utility and reliability come before hype.
- **Keep it maintainable:** clear structure, reusable modules, and readable code.
- **Ship responsibly:** environment variables, logs, deployment docs, and security basics.
- **Improve continuously:** refactor when it makes the product faster, safer, or easier to extend.
